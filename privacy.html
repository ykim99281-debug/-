전설의 검 강화하기 (웹 게임 및 Android 앱) · 시행일 2026년 11월 14일

「전설의 검 강화하기」 운영자(이하 “운영자”)는 이용자의 개인정보를 소중히 다루며, 게임에 꼭 필요한 최소한의 정보만 처리합니다.

1. 처리하는 정보

항목설명
아이디가입할 때 이용자가 정한 2~10자의 아이디(닉네임). 랭킹·월드·채팅에서 다른 이용자에게 보입니다.
비밀번호 확인값비밀번호 원문은 저장하지 않고, 원문을 알 수 없게 변환한 값(해시)만 저장합니다.
로그인 확인 정보계정 주인만 자기 기록을 고칠 수 있도록, 게임이 자동으로 만든 임의의 식별 주소(실제 이메일이 아닙니다)와 비밀번호 확인값으로 로그인 확인 정보를 만듭니다. 실제 이메일 주소는 받지 않습니다.
게임 기록골드, 검 단계, 업적, 강화·대련 기록, 차단 목록 등 게임 진행 정보
랭킹 기록아이디, 최고 강화 단계, 골드, 등록 시각
월드·대련 정보월드 화면에 접속해 있는 동안의 캐릭터 위치, 대련 신청·결과
채팅 메시지웹 버전 전체 채팅에 쓴 글 (욕설·전화번호는 자동으로 가려짐)
신고 내용신고한 사람·신고 대상 아이디, 신고된 메시지
가입·동의 시각계정 생성 시각, 이용 규칙·개인정보처리방침 동의 시각

이름, 전화번호, 이메일, 주소, 위치정보(GPS), 연락처, 사진, 광고 ID 등은 수집하지 않습니다. 광고와 유료 결제도 없습니다.

2. 이용 목적

로그인과 게임 진행 저장, 랭킹·월드 대련·채팅 기능 제공, 욕설·괴롭힘·부정행위 방지와 신고 처리에만 사용합니다.

3. 보관 기간과 삭제

  • 계정 정보와 게임 기록: 계정을 삭제하면 즉시 삭제합니다.
  • 채팅 메시지: 작성 후 24시간이 지나면 자동 삭제합니다.
  • 월드 위치: 월드 화면을 나가면 삭제합니다.
  • 신고 내용: 관리자가 처리를 마치면 삭제합니다.

4. 계정 삭제 방법

앱·게임 안에서: 📊 기록·설정 탭 → 👤 내 계정 · 정책 → 🗑️ 내 계정 삭제 → 비밀번호 입력 → 영구 삭제
웹에서: 계정 삭제 요청 페이지에서 아이디와 비밀번호로 바로 삭제할 수 있습니다.
이메일: 비밀번호를 잊었거나 보호자가 삭제를 원하면 아래 이메일로 아이디를 알려 주세요.
