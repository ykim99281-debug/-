📜 이용 규칙

전설의 검 강화하기 (웹 게임 및 Android 앱) · 시행일 2026년 11월 13일

모두가 즐겁고 안전하게 게임할 수 있도록 아래 규칙을 지켜 주세요. 계정을 만들면 이 규칙에 동의한 것으로 봅니다.

1. 금지하는 내용과 행동

  • 욕설·비하·혐오 표현: 다른 사람이나 성별·나이·외모·지역·장애·국적 등을 깎아내리는 말
  • 괴롭힘·따돌림·협박: 특정 사람을 계속 놀리거나 위협하거나 따돌리는 행동
  • 성적인 내용과 폭력적·잔인한 내용, 위험한 행동을 부추기는 내용
  • 개인정보 공유: 자신이나 다른 사람의 실명, 전화번호, 주소, 학교, SNS 계정, 사진 등을 올리는 것
  • 만나자고 하기: 게임 밖에서 만나자고 하거나 다른 메신저로 옮기자고 하는 것
  • 사칭: 관리자·제작자나 다른 사람인 척하는 아이디·메시지
  • 도배·광고: 같은 말 반복, 홍보, 링크 퍼뜨리기
  • 부정행위: 해킹, 프로그램 조작, 버그 악용, 다른 사람 계정 사용, 게임 기록 조작
  • 현금 거래: 게임 골드·아이템·계정을 돈이나 물건으로 사고파는 것

2. 신고와 차단

채팅(웹 버전): 메시지를 누르면 🚩 신고와 🚫 차단 버튼이 나옵니다.
월드: 상대 캐릭터를 누르면 🚩 신고와 🚫 차단 버튼이 나옵니다.
차단한 사람의 채팅과 월드 캐릭터는 보이지 않고, 대련 신청은 자동으로 거절됩니다. 차단은 📊 기록·설정 탭에서 풀 수 있습니다.

3. 규칙을 어기면

관리자는 신고를 확인하고 상황에 따라 메시지 삭제 → 채팅 금지(10분·1시간) → 계정 정지 → 계정 삭제 순으로 조치합니다. 심각한 경우 바로 정지하거나 삭제할 수 있습니다.

4. 게임 재화

골드, 검, 방지권 같은 게임 속 재화는 현금 가치가 없으며 돈으로 바꾸거나 환불할 수 없습니다. 유료 결제와 광고는 없습니다.

5. 계정

  • 비밀번호는 다른 사람에게 알려 주지 마세요. 아이디에 실명을 쓰지 마세요.
  • 만 14세 미만은 보호자의 동의를 받은 뒤 가입해 주세요.
  • 📊 기록·설정 탭의 🗑️ 내 계정 삭제 또는 계정 삭제 페이지에서 언제든 계정을 지울 수 있습니다.

6. 서비스 변경

게임 내용과 기능은 더 나은 서비스를 위해 바뀌거나, 부득이한 경우 중단될 수 있으며 이때는 게임 안에서 미리 알립니다.
